# InspectorCartridge 🖨️

Telegram-бот для автоматизации учёта картриджей на складах.
Инженер берёт картридж, отмечает это в боте — и остатки обновляются автоматически.
Больше не нужно тратить время на постоянные инвентаризации, всё прозрачно и доступно любому сотруднику.


```bash
## 🎯 Основные функции
- 📥 **Приход** — добавить картридж на склад за секунду  
- 📤 **Расход** — списание с комментарием, проверка остатков  
- 📊 **Складской запас** — мгновенно узнать, что есть на складе  
- 📜 **История операций** — полная прозрачность движений  
- 🔄 **Сброс** — если что-то пошло не так  
- 🚪 **Выйти** — безопасное завершение сессии
```

## 🛠 Установка

git clone https://github.com/PreparingShaders/InspectorCartridge.git  
cd InspectorCartridge  

python -m venv .venv  
source .venv/bin/activate  # Linux/macOS  
.venv\Scripts\activate     # Windows  

pip install -r requirements.txt  

# Настройка токена бота в main.py
python main.py


## 🗂 Структура проекта

main.py             # Запуск бота  
old_main.py         # Старая версия  
db.py               # Работа с базой данных  
actions.py          # Логика операций  
auth/               # Авторизация  
handlers/           # Обработчики команд  
ui/                 # Меню и клавиатуры  
cartridges.db       # База данных картриджей

README.md           # Документация  
__pycache__/        # Скомпилированные файлы


## 🗄 База данных

- SQLite3  
- Таблицы:  
  - warehouses — склады  
  - cartridge_types — модели картриджей  
  - transactions — история операций (приход/расход)


## 📦 Зависимости

- pyTelegramBotAPI — работа с Telegram API  
- pyzbar, pillow — работа со штрих-кодами  
- aiohttp, aiohappyeyeballs — асинхронные сетевые операции  
- другие стандартные библиотеки Python
